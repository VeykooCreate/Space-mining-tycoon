# Space Mining Tycoon — Halloween V5

## Changements
- Missions d'Halloween répétables avec réinitialisation quotidienne des objectifs réclamables, à la date locale du jeu.
- Niveaux persistants pour les missions quotidiennes répétables : les objectifs augmentent de 1,8× par niveau et les récompenses de 1,45×.
- Point rouge sur le menu des missions Halloween lorsqu'une récompense est disponible, ainsi qu'un indicateur dans chaque mission prête à être réclamée.
- Coûts des bâtiments augmentés fortement, avec une progression plus exigeante entre les planètes.
- Prix des 20 maléfices multipliés par 1 000.
- Suppression du cadeau initial de 250 bonbons pour éviter un démarrage trop facile.

## Installation
Tester d'abord sur une branche séparée. Remplacer les fichiers du site par ceux de cette archive, attendre le déploiement puis faire un rechargement forcé. Tester les sauvegardes et les achats avant publication.
